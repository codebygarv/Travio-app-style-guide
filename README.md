# Travio

An AI-powered travel suggestion and companion application.

## Overview

Travio is a modern web application that provides completely AI-driven travel suggestions to help users find the best destinations tailored to their preferences. It features a soothing Sage Green design language, crisp slate typography, and intuitive mobile-first navigation.

## Core Features

- **AI-Driven Suggestions:** Chat with the AI to get customized travel itineraries and recommendations.
- **Location Awareness:** Automatically fetches current location to provide nearby famous attractions.
- **Favorites & Discovery:** Save the best places and explore broad categories and specific destinations.
- **User Authentication:** Integrated login and profile management.

## App Architecture

The application is structured around a 5-tab navigation system:
1. **Home:** Location-based recommendations and nearby attractions.
2. **Explore:** Category browsing and destination deep-dives.
3. **AI Chat:** The core conversational interface for personalized travel planning.
4. **Favorites:** Saved locations and "Best Places" grids.
5. **Profile:** User settings and social features.

## Tech Stack

- **Framework:** React + Vite
- **Icons:** lucide-react
- **Linting:** oxlint

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

### Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the app for production.
- `npm run lint`: Runs oxlint to check for code issues.
- `npm run preview`: Previews the production build locally.
